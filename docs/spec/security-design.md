# 安全与执行环境设计

## 授权边界

实验对象来自自有或获授权的环境。每个案例登记来源、仓库、固定提交、材料许可和预期目标。操作者可提交、审核与读取自己的任务，项目维护者管理案例注册表、工具镜像和策略。宿主身份、数据库权限和文件权限承载 MVP 的访问边界。制品默认存于私有目录。

人工审批展示源码提交、镜像及材料摘要、构建与运行配方、网络策略和资源预算。批准绑定任务、计划摘要和身份，并在待审期限内提交。执行器在每次启动前检查批准记录和实际输入，拒绝执行期限耗尽、摘要不符或策略漂移的任务。

## 执行环境

1. **获取**。准备阶段的适配器按允许列表获取公开资料，检查重定向和连接目标。拒绝私有地址、回环和本地 URL。离线案例使用已固定快照。
2. **检查**。Git 解析禁用未经授权的钩子、外部 diff 驱动和子模块拉取。解析器在独立受限进程读取不可信源码。案例构建配方经审核后固化。
3. **构建与回放**。一次性 Docker 容器使用 `--network none`、非 root UID、只读根文件系统、`--cap-drop ALL`、`no-new-privileges` 及 seccomp。输入只读挂载，写入仅限有上限的工作区。凭证、控制面网络和 Docker socket 留在容器外。 [Docker 网络隔离](https://docs.docker.com/engine/network/drivers/none/) · [Docker 资源约束](https://docs.docker.com/engine/containers/resource_constraints/)
4. **资源控制**。CPU、内存、PID、可写空间按 SRS 限制。执行器检查限制实际生效，达到时间上限时终止并清理容器。单次工具调用原始日志总量上限 16 MiB，按角色记录截断。受影响的必要证据进入不完整判定。
5. **证据收集**。容器停止后按角色和大小限制读取产物，拒绝符号链接、设备文件和越界路径。操作日志保留摘要、退出状态、限额事件、审核身份及原因码。报告引用私有证据，渲染文本时转义不可信内容。

真实案例使用专用可重置 VM，VM 内运行一次性容器。二进制及高风险样本在扩展阶段由一次性 VM 后端运行，回传相同结构的制品。

## 威胁与验证

- **提示注入**。公告、日志、diff 和注释只作数据。校验模型输出类型与证据引用。工具执行由确定性策略授权。
- **命令和路径注入**。工具使用固定命令模板、参数数组及结构化参数。拒绝自由 shell、危险路径与额外挂载。
- **越权与重复执行**。以批准摘要和执行代次约束调用。旧进程无法覆盖记录，接管前回收遗留容器。
- **供应链与证据篡改**。固定镜像和依赖摘要，核对制品。审计记录保存清单摘要以支持来源核验。
- **数据泄露**。模型默认离线，开启外部模型时只送出配置允许的字段。日志脱敏，原始种子与诊断仅进入私有制品。

验收包含无外网、非 root、无宿主凭证、越界访问失败、预算耗尽清理、审批重放拒绝和恶意文本不触发工具调用。用例见 [测试与评估计划](test-plan.md)。
